How to Use Droppp

Droppp transfers files locally between devices connected to the same Wi-Fi network.

1

Run the local host server

Turn on the toggle button on the app screen to start the local host server. The server works only while your iOS device is connected to Wi-Fi.

2

Copy the URL or view the QR code

Tap the URL shown in the app to copy the address or view its QR code.

3

Open the address on the same Wi-Fi

On a nearby device connected to the same Wi-Fi network, open the address in a browser.

4

Download or upload files

From the browser page, download files or drag files onto the screen to upload them. The file library is stored locally on your iOS device and is not shared.

5

Manage files saved in Droppp

Files saved in Droppp on your iOS device can be shared or deleted. You can also drag multiple items and drop them into another app easily.

Other Guides

Helpful notes for adding, selecting, and managing files in Droppp.

Drop photos or files into Droppp

Drag photos or files from your iOS device and drop them onto the Droppp screen to add them to the file library.

Select all files

After selecting files, tap the selected item count in the lower-left corner to select all files.

The local server stops automatically

If you leave the Droppp app screen or the display turns off, the local server stops.

Automatic screen dimming while the server is on

While the local server is running, your iOS device stays awake so the display does not turn off. When automatic screen dimming is enabled, Droppp keeps the current brightness for 10 seconds, then lowers the screen to the minimum brightness automatically. You can turn this feature on or off in Settings.
